プライバシーポリシー（代表室の道具）

最終更新：2026年11月14日

だれが使うか

この道具は、持ち主が自分の YouTube チャンネルのために使う個人用のプログラムです。使うのは持ち主の Google アカウントだけで、ほかの人のアカウントのデータは扱いません。

扱うデータ

持ち主が許可した範囲で、YouTube API サービスを通して、持ち主の自分のチャンネルの数字（表示回数・クリック率・再生・視聴時間・視聴者維持率・流入元など）と、チャンネルの基本情報を読みます。また、持ち主の動画とサムネイルを、持ち主のチャンネルに上げます。

データの置き場所と共有

読んだデータと、許可の情報（トークン）は、持ち主のパソコンの中にだけ保存します。第三者に売ったり、渡したり、広告に使ったりしません。

保存の期間と削除

YouTube API サービスの開発者ポリシーに従って保存します。許可は、持ち主がいつでも Google アカウントの「サードパーティのアクセス」（https://myaccount.google.com/connections）から取り消せます。取り消したとき、または持ち主が求めたときは、保存したデータを消します。

YouTube と Google のポリシー

この道具は YouTube API サービスを使っています。YouTube 利用規約と Google プライバシー ポリシーも適用されます。

Privacy Policy (summary in English): This personal tool is used only by its owner. Through the YouTube API Services and with the owner's authorization, it reads analytics and basic information for the owner's own YouTube channels and uploads the owner's videos and thumbnails. Data and authorization tokens are stored only on the owner's computer and are never sold or shared with third parties. Authorization can be revoked at any time at https://myaccount.google.com/connections.
