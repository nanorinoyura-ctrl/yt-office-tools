代表室の道具

この道具は、持ち主が自分で運営している YouTube チャンネルのために、持ち主自身が使う、個人用のプログラムです。一般の人に向けた公開のサービスではありません。

  • YouTube Analytics API・YouTube Reporting API で、持ち主の自分のチャンネルの数字（表示回数・クリック率・再生・視聴時間など）を読みます。
  • YouTube Data API で、持ち主の自分のチャンネルに動画とサムネイルを上げます。
  • 使うのは、持ち主の Google アカウントだけです。

プライバシーポリシー

This is a personal tool used only by its owner to read analytics for, and upload videos to, the owner's own YouTube channels through the official YouTube APIs. It is not a public service. Privacy Policy
