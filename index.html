代表室の道具

最終更新：2026年11月14日

この道具は、持ち主が個人で運営している3つの YouTube チャンネル（「IF:ZERO」「大地の解読室」「歴史の脇役」）のために、持ち主ひとりが自分のパソコンで使う、社内用のプログラムです。一般の人に向けたサービスではなく、ほかの人はログインも利用もできません。

できること

  • 自分のチャンネルの数字を読む：YouTube Analytics API・YouTube Reporting API で、持ち主が許可した自分のチャンネルの数字（表示回数・クリック率・再生・視聴時間など）を読みます。
  • 自分の動画を直す：YouTube Data API で、持ち主の自分の動画の題名・説明・サムネイルを差し替えたり、公開の予約をしたりします。
  • 企画のための調べもの：YouTube Data API で、自分のジャンルの公開動画を検索し、公開されている動画とチャンネルの情報（題名・公開日・再生回数など）を読みます。いまどんな話題が見られているかを知るためと、自分の企画がほかの人の最近の動画と重なっていないか確かめるために使います。
  • 同じジャンルのチャンネルの新しい動画を見る：決まった公開チャンネル（約50）の新しい公開動画の一覧を、YouTube の数字のまま読みます。順位づけや集計、新しい数字の計算はしません。

データの扱い

  • 結果は持ち主のパソコンの中のメモに出します。メモの整理と作業の手伝いに AI アシスタント（Anthropic・OpenAI のクラウドのサービス）を使うため、データの一部が送られることがあります。それ以外の人に見せたり、公開したり、売ったりしません。
  • ほかのチャンネルの情報は、YouTube API サービスの開発者ポリシーに従い、30日以内に消すか、取り直します。
  • くわしくはプライバシーポリシーをご覧ください。

Daihyoshitsu Tools

Last updated: November 14, 2026

This is an internal tool used by a single person, the owner, on the owner's own computer, for the three YouTube channels the owner runs as an individual creator ("IF:ZERO", "大地の解読室" and "歴史の脇役"). It is not a public service. No one else can sign in to it or use it.

What it does

  • Reads analytics for the owner's own channels through the YouTube Analytics API and the YouTube Reporting API, with the owner's OAuth authorization (impressions, click-through rate, views, watch time, and similar metrics).
  • Updates the owner's own videos through the YouTube Data API: titles, descriptions and thumbnails, and scheduled publishing.
  • Research for content planning: searches public videos in the owner's genres and reads public information about videos and channels (title, publish date, view count, etc.) through the YouTube Data API, to see which topics are being watched and to check that the owner's planned videos do not copy other creators' recent videos.
  • Watches new videos in the same genres: reads the list of newly published public videos from a fixed set of about 50 public channels, with figures as provided by YouTube. It does not rank, aggregate or calculate new metrics from them.

How data is handled

  • Results appear in local notes on the owner's computer. The owner uses AI assistant services (cloud services by Anthropic and OpenAI) to organize notes and assist with the work, so some data may be sent to them. Otherwise results are not shown to anyone else, published or sold.
  • Information about other channels is deleted or refreshed within 30 days, as required by the YouTube API Services Developer Policies.
  • See the Privacy Policy for details.
